The Loom

Pick a region of Iran, load its documented palette and motif vocabulary, and start setting knots. Each region carries its own colors, knot structure and layout — drawn from a handful of rug-history sources as a starting scaffold, not a finished dataset.

Drag in Knot mode to lay a run of knots; in Stamp mode, click to set a whole motif — a motif is still just a cluster of individually tied knots. The small mark on each knot (a bar vs. an offset tick) shows symmetric vs. asymmetric structure for whichever region was active when it was tied. The stamp set changes per region and per style family: curvilinear court regions get rounded, lobed shapes; geometric village and nomadic regions get hard-stepped ones built from the same knot grid at a coarser scale — that stepping is how real curves get approximated in a hand-knotted rug too, not a simplification unique to this tool. Newly tied knots sit loose with visible gaps until you beat that row — the Beat button uses whichever tool the selected region actually uses to pack a row tight before the next one starts.

Warp — the loom's bare threads, never colored
Weft — the over-under pass that locks a finished row; fine city-workshop regions show it as a tighter double pass (depressed warp), village/nomadic regions as one looser pass
Knot — one hand-tied loop; this is the entire pattern
